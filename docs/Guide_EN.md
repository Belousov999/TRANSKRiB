# TRANSKRiB — Guide (EN)

## What it is
TRANSKRiB is a local pipeline that converts media to WAV (mono 16k) and transcribes it.

## Repo structure
- app/convertor — converter
- app/ttgp — GPU transcription worker
- requirements — dependencies
- docs — documentation

## Quick start (draft)
1) Install Python + deps (see requirements)
2) Run converter
3) Run TTGP
