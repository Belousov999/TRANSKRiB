# CTPortable — ТЗ

## Цель
Сделать переносимый конвертор + GUI в браузере как основной вход в TRANSKRiB.

## Требования
- Без жёстких путей вида D:\... — все пути относительные от папки приложения/конфига.
- GUI (web):
  - выбор модели: LargeV3 / turbo / (опционально) TurboEnRu3.2
  - Download / Remove / Validate моделей с HuggingFace (легально)
  - кнопка Transcribe активна только если:
    - NVIDIA/CUDA доступно
    - VRAM >= порога
    - модель установлена и проверена
  - политика WAV: удалять после транскрибации / сохранять в WAV-архив

## Примечания
- Конфиг: config.yaml/json рядом с приложением
- Каталоги: input / tmp / result / logs / models
