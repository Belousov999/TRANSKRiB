# TRANSKRiB — руководство (RU)

## Что это
TRANSKRiB — локальный пайплайн конвертации аудио/видео в WAV (mono 16k) и транскрибации.

## Структура репозитория
- app/convertor — конвертор
- app/ttgp — GPU-воркер транскрибации
- requirements — зависимости
- docs — документация

## Быстрый старт (черновик)
1) Установить Python и зависимости (см. requirements)
2) Запуск конвертора
3) Запуск TTGP
